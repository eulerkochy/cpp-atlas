# std::linear_congruential_engine<UIntType,a,c,m>::min

Source: https://en.cppreference.com/w/cpp/numeric/random/linear_congruential_engine/min

```cpp
static constexpr result_type min(); // (since C++11)
```

Returns the minimum value potentially generated by the random-number engine.

## Return value

`c == 0u ? 1u: 0u;`

## Complexity

Constant.
