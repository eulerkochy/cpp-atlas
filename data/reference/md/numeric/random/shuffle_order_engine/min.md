# std::shuffle_order_engine<Engine,K>::min

Source: https://en.cppreference.com/w/cpp/numeric/random/shuffle_order_engine/min

```cpp
static constexpr result_type min(); // (since C++11)
```

Returns the minimum value potentially generated by the engine adaptor. This value is equal to `e.min()` where `e` is the underlying engine.

## Parameters

(none)

## Return value

The minimum potentially generated value.

## Complexity

Constant.
