# std::independent_bits_engine<Engine,W,UIntType>::max

Source: https://en.cppreference.com/w/cpp/numeric/random/independent_bits_engine/max

```cpp
static constexpr result_type max(); // (since C++11)
```

Returns the maximum value potentially generated by the engine adaptor. This value is equal to 2^(w) - 1.

## Parameters

(none)

## Return value

The maximum potentially generated value.

## Complexity

Constant.
