# std::philox_engine<UIntType,w,n,r,consts>::max

Source: https://en.cppreference.com/w/cpp/numeric/random/philox_engine/max

```cpp
static constexpr result_type max(); // (since C++26)
```

Returns the maximum value potentially generated by the random-number engine.

## Return value

`2w-1`

## Complexity

Constant.
