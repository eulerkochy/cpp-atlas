# C++ keyword: requires (since C++20)

Source: https://en.cppreference.com/w/cpp/keyword/requires

## Usage

- specifies a constant expression on template parameters that evaluate a requirement

  - within such a requirement, introduces a nested requirement

- in a template declaration, specifies an associated constraint
