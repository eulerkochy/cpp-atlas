# std::experimental::any::~any

Source: https://en.cppreference.com/w/cpp/experimental/any/~any

```cpp
~any(); // (library fundamentals TS)
```

Destroys the contained object, if any, as if by a call to `clear()`.

## See also

- [`clear`](https://en.cppreference.com/w/cpp/experimental/any/clear): destroys contained object (public member function)
