# C++ keyword: consteval (since C++20)

Source: https://en.cppreference.com/w/cpp/keyword/consteval

## Usage

- `consteval` declaration specifier
- *lambda-declarator* that explicitly specifies the function call to be an immediate function

(since C++23):

- `consteval` `if` statement
