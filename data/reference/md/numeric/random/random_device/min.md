# std::random_device::min

Source: https://en.cppreference.com/w/cpp/numeric/random/random_device/min

```cpp
static constexpr result_type min(); // (since C++11)
```

Returns the minimum value potentially generated by the random-number engine.

## Return value

`0u`

## Complexity

Constant.
