# std::mersenne_twister_engine<UIntType,w,n,m,r,a,u,d,s,b,t,c,l,f>::max

Source: https://en.cppreference.com/w/cpp/numeric/random/mersenne_twister_engine/max

```cpp
static constexpr result_type max(); // (since C++11)
```

Returns the maximum value potentially generated by the random-number engine.

## Return value

`2w-1`

## Complexity

Constant.
