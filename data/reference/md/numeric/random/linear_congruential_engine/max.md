# std::linear_congruential_engine<UIntType,a,c,m>::max

Source: https://en.cppreference.com/w/cpp/numeric/random/linear_congruential_engine/max

```cpp
static constexpr result_type max(); // (since C++11)
```

Returns the maximum value potentially generated by the random-number engine.

## Return value

`m - 1u`

## Complexity

Constant.
