# std::rel_ops Symbol Index

Source: https://en.cppreference.com/w/cpp/symbol_index/rel_ops

There are no identifiers available from the standard library in the namespace `std::rel_ops`.

The namespace exists for automatic generation of comparison operators, and is deprecated in C++20 because of the three-way comparison operator.

## See also

- [`operator!=`](https://en.cppreference.com/w/cpp/utility/rel_ops/operator_cmp) (deprecated in C++20), [`operator>`](https://en.cppreference.com/w/cpp/utility/rel_ops/operator_cmp), [`operator<=`](https://en.cppreference.com/w/cpp/utility/rel_ops/operator_cmp), [`operator>=`](https://en.cppreference.com/w/cpp/utility/rel_ops/operator_cmp): automatically generates comparison operators based on user-defined `operator==` and `operator<` (function template)
