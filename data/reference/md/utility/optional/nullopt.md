# std::nullopt

Source: https://en.cppreference.com/w/cpp/utility/optional/nullopt

```cpp
// Defined in header <optional>
inline constexpr nullopt_t nullopt{/*unspecified*/}; // (since C++17)
```

`std::nullopt` is a constant of type `std::nullopt_t`. Used to indicate that an `std::optional` does not contain a value.

- [`nullopt_t`](https://en.cppreference.com/w/cpp/utility/optional/nullopt_t) (C++17): indicator of an `std::optional` that does not contain a value (class)
